# Edita y prueba tus cambios. Después revisa exactamente lo que vas a confirmar:

git diff --cached --stat
git diff --cached

5. CREAR UNA RAMA PARA UNA VERSIÓN ALTERNATIVA

6. COMPROBACIONES DE SEGURIDAD

git status --short
git ls-files | Select-String -Pattern '(^|/)(\.env|\.clasp\.json|config\.json)$|\.(db|sqlite|log|key|pem|p12|pfx|keystore|jks)$'

Si aparece una credencial, no hagas push. Retírala, revócala en el proveedor y vuelve a revisar todo el historial. Nunca uses fechas falsas: cada commit debe reflejar trabajo real ejecutado ese día.
