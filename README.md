# Bitácora de Conductores

Aplicación móvil Xamarin para registrar y consultar la bitácora operativa de conductores, con proyectos compartido, Android e iOS dentro de la solución `ProyectoAppMovil.sln`.

El proyecto conserva su historial remoto original. Para compilarlo se necesita un entorno Visual Studio compatible con las cargas móviles heredadas usadas por la solución; esta PC no cuenta actualmente con ese SDK.

Consulta `PROVENIENCIA.md` y `PASOS_GIT_GITHUB.txt` antes de publicar cambios.
